# 寻应 Logo 使用说明

## 当前版本

网站已采用方案 A“双环回响”作为正式主标。所有页面页眉、首页导航、登录页、免责声明、管理后台与浏览器 favicon 均使用该标志。

## 文件

- `xunying-logo.svg`：白底横向主标
- `xunying-logo-dark-bg.svg`：深色背景横向标
- `xunying-mark.svg`：透明底品牌图形
- `xunying-mark-dark.svg`：深色背景品牌图形
- `xunying-app-icon.svg`：网站图标、头像、桌面图标
- `xunying-badge.svg`：圆形比赛展示徽章
- `brand-preview.html`：全部标志的预览页
- `xunying-brand-preview.png`：完整品牌预览图
- `xunying-logo-1200x320.png`：可直接插入 PPT 的横向主标
- `xunying-app-icon-512.png`：可直接上传的方形网站图标
- `xunying-badge-1024.png`：可直接用于比赛封面的圆形徽章

## 设计含义

- 圆形双层边框借鉴高校校徽的徽章结构。
- 放大镜代表“寻找资源”。
- 镜内两条反向接力箭头代表“发出需求、收到回应”。
- 青色节点代表校内互助网络，橙色代表正在等待回应的人。
- 深蓝承接杭电视觉，青绿延续现有网站主色，橙色用于关键提醒。

## 使用建议

网页页眉和导航使用 `xunying-mark.svg`，浏览器 favicon 与手机图标使用 `xunying-app-icon.svg`。横向主标适合 PPT、活动物料和正式展示；圆形徽章适合比赛封面与团队展示。

杭电正式校徽属于学校官方标识。本设计只借鉴圆形徽章结构、深蓝配色与流线构成，不直接复制校徽，也不表示学校官方认证。
